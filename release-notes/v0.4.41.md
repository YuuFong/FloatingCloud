# FloatingCloud v0.4.41

本版修复设置页“前往下载”按钮在网易云插件窗口中无法打开浏览器的问题。

## 下载

- **FloatingCloud-Setup.exe**：Windows x64 一键安装器，内置本版 FloatingCloud、BetterNCM 和 InfLink-rs。点击“一键安装 / 修复”即可安装内置的 v0.4.41；“在线更新 FC”可获取 GitHub 最新正式版。
- **FloatingCloud-v0.4.41.plugin**：已有 BetterNCM 与 InfLink-rs 时用于手动安装。退出网易云音乐后替换旧版插件包，再启动网易云。

## 更新内容

- “前往下载”通过 BetterNCM 的外部链接接口打开系统浏览器。
- 安装器支持识别带预发布后缀的 FC 插件包；构建自检核对内置插件版本。

适用 Windows x64、网易云音乐 3.1.42（不包含 3.1.43）。安装器未签名；请从本仓库官方 Release 下载。
