# FloatingCloud v0.4.42

本版改善歌词行切换动画和原文空格显示。

## 下载

- **FloatingCloud-Setup.exe**：Windows x64 一键安装器，内置本版 FloatingCloud、BetterNCM 和 InfLink-rs。
- **FloatingCloud-v0.4.42.plugin**：已有 BetterNCM 与 InfLink-rs 时用于手动安装。

## 更新内容

- 主行歌词播放完后，与上划滚动同步渐隐，避免瞬间消失。
- 保留歌词原文中的连续空格；当逐词片段含空格而整行文本漏掉时，在文字内容一致的前提下恢复空格。

适用 Windows x64、网易云音乐 3.1.42（不包含 3.1.43）。安装器未签名；请从本仓库官方 Release 下载。
