# FloatingCloud v0.4.40

本版改善歌词切换动画和纯音乐频谱的切入、切出效果。

## 下载

- **FloatingCloud-Setup.exe**：Windows x64 一键安装器，包含 BetterNCM、InfLink-rs 和 FloatingCloud。
- **FloatingCloud-v0.4.40.plugin**：已有 BetterNCM 与 InfLink-rs 时用于手动安装。退出网易云音乐后，替换旧版插件包并重新启动。

## 更新内容

- 副行歌词升为主行时，字号平滑过渡。
- 歌词与纯音乐频谱切换时增加过渡，避免闪烁和短暂空白。
- 对“此歌曲为没有填词的纯音乐，请欣赏”等占位提示按 TBL 的纯音乐文档逻辑识别，显示频谱。

适用 Windows x64、网易云音乐 3.1.42（不包含 3.1.43）。安装器未签名；请从本仓库官方 Release 下载。
