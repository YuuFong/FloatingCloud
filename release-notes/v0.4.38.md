# FloatingCloud v0.4.38

本次带来 **插件内置更新检查** 和真正的 **Windows 一键安装器**。已在 Windows 实机确认最新版安装器能完成 BetterNCM + InfLink-rs + FloatingCloud 的自动部署。

## 下载哪个文件？

- **`FloatingCloud-Setup.exe`（推荐）**：Windows x64 一键安装器。打开后自动定位网易云音乐，点击「一键安装 / 修复」，即可安装所需的 BetterNCM、InfLink-rs 和 FloatingCloud。三个组件的程序文件已打包在安装器内，正常安装不依赖 GitHub API，也不会再因旧版 GitCode 接口 HTTP 406 中断。
- **`FloatingCloud-v0.4.38.plugin`（手动安装）**：适合已经安装 BetterNCM 与 InfLink-rs 的用户。关闭网易云，将此文件放入 BetterNCM 插件目录（常见为 `C:\betterncm\plugins`，或自定义 `BETTERNCM_PROFILE\plugins`），移走旧版 FloatingCloud 包，再启动网易云。

## v0.4.38 更新内容

- 设置页新增「插件版本与更新」：每天最多自动检查一次 GitHub 正式 Release，也可手动检查；有新版本时显示下载入口。
- 改善版本比较、离线／网络失败、API 限流的提示，不影响歌词播放。
- 新增集成安装器：支持检测网易云路径、按需安装 BetterNCM、自动安装 InfLink-rs、保留用户设置、备份旧版和完成后启动网易云。
- 安装器内置完整的 **FloatingCloud v0.4.38**、**InfLink-rs v3.4.0**、**BetterNCM v1.3.4 (x64)**，并保留第三方许可说明。
- 桌面双行滚动歌词、逐词高亮、翻译、副歌辉光、纯音乐频谱、本地歌词支持等原有功能继续保留。

## 适用环境与说明

- Windows x64
- 网易云音乐 **3.1.42**（不包括 3.1.43 及其他未适配版本）
- 安装过程中可能需要 Windows 管理员权限；如果缺少微软 VC++ 运行库，安装器会联网下载安装。
- 安装器暂未签名，Windows SmartScreen 可能显示警告；请仅从本仓库官方 Release 下载。
- InfLink-rs 和 BetterNCM 属于独立第三方开源项目。来源及许可：[InfLink-rs](https://github.com/apoint123/inflink-rs) / [BetterNCM](https://github.com/std-microblock/chromatic/tree/1.3.4)。

推荐已安装过旧版的用户在升级之前退出网易云音乐；安装器会自动处理后台进程关闭及旧版插件备份。
