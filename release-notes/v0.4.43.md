# FloatingCloud v0.4.43

本版移除网易云音乐 3.1.42 的版本门槛，修复更新到 3.1.43 后插件被 BetterNCM 跳过的问题。

## 下载

- **FloatingCloud-Setup.exe**：Windows x64 一键安装器，内置本版 FloatingCloud、BetterNCM 和 InfLink-rs。
- **FloatingCloud-v0.4.43.plugin**：已有 BetterNCM 与 InfLink-rs 时用于手动安装。关闭网易云后替换旧版插件包，再启动网易云。

## 更新内容

- 从插件清单移除网易云补丁版本范围限制。
- 安装器不再因网易云版本不是 3.1.42 而拒绝安装。

已在网易云 3.1.43.205627 上确认 BetterNCM 加载 FloatingCloud 原生组件并显示歌词窗。实际播放与歌词数据仍取决于当前 BetterNCM、InfLink-rs 和网易云环境。安装器未签名；请从本仓库官方 Release 下载。
